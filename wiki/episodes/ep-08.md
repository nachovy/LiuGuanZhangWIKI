# 第8集：益州之战

**集数**：第8集  
**故事时间**：194年末至196年2月（东汉兴平元年末至建安元年）

---

## 本集概要

刘焉死后局势成熟，刘官章整军备战，联合张鲁南北夹击，历经约15个月的战争，拿下整个益州，刘璋出降，获得20亿钱府库。

---

## 主要事件

### 整军备战（194年12月）

- 大雪营扩至400人（人马俱甲），从张鲁处以3万支箭矢换400匹马。
- 安汉军学院第二期、政学院第一期共40余人毕业，分配地方。
- 发布讨伐檄文：列刘璋五大罪状（背祖忘本、信任奸邪、纵兵殃民、闭关阻兵、屠害旧臣）。

### 部署计划

| 方向 | 将领 | 任务 |
|------|------|------|
| 粮道保护 | 马忠 | 保护水路粮道，阻截援军 |
| 西北 | 严颜 | 屯军西北，围点打援 |
| 北线威胁 | 甘宁 | 再次威胁剑门关 |
| 主攻 | 刘官章 | 联合张鲁南北夹击 |

### 拿下江阳（195年1月）

- 围城一个多月，拿下江阳（江阳郡治）。

### 大战安汉（195年1月-3月）

- **[庞义](../historical/pang-yi.md)**率军1万围攻阆中阻止甘宁。
- **赵韪**率军1.5万进攻安汉（广汉郡策应）。
- 战术：汉山营正面迎战；重兵4000在山上游动（恐吓阻援）；大雪营400骑兵迂回穿插冲锋，从侧翼凿阵。
- 结果（195年3月）：赵韪完全撤军。
  - 我方伤亡1600人（战死600，伤1000）；敌方伤亡6000（多为追杀/溺亡）。
  - 抚恤金3980万钱花销。
- 赵韪把先锋军和后营分开后，刘官章让300轻骑只追击向北溃逃的部队，将其逼入河中；城内1000步兵负责接应各营撤回，形成轮换撤退，避免被东州兵反包围。

### 广汉、剑门与白水关（195年春—冬）

- 东州兵败后，刘官章没有立即把战线推入广汉腹地，而是让严颜在南线边打边收降；甘宁率约2000名重兵翻山威胁**剑门关**，马忠负责袭扰粮道，黄权率重兵驻垫江，防止张鲁或刘璋从侧后突袭。
- 甘宁攻下剑门关时本部损失约2000人，刘官章允许其就地补充；白水关因粮道被截随后投降。张嶷负责协助接收和守备，黄权改守阆中，甘宁长期驻剑门关以防张鲁背刺。
- 刘官章向各军说明，东州兵若接受改编，骨干可保留最多3000名私兵；投降越早，保留的人口、土地和军队待遇越高，拒绝改编者回乡务农。
- 战争中军纪按“四禁令五注意”执行：不得私掠府库、杀良冒功、损害庄稼、调戏妇女、虐待俘虏或随地便溺；官方赏赐和抚恤由专门官员发放，不经将领之手，以维持士兵对刘官章的直接依附。

### 严颜取犍为郡北部（195年10月）

- 严颜部拿下**犍为郡**北部，东州兵家属秋毫无犯，军心动摇后出现大量逃兵。

### 梓潼诱敌（195年11月）

- 甘宁调回，黄权守剑门关。
- 刘官章与甘宁、六名亲兵骑马靠近梓潼城，摘盔喊话"谁敢下城决死"。
- 梓潼守将中计，派200骑追击，被提前布置的伏击圈包围（马忠、周康）。
- 随后梓潼守军出兵救援被围骑兵，大部队围住救援军。
- 用缴获衣服骗开城门，拿下梓潼。
- 梓潼府库充盈：扣除赏赐后剩余1亿2000万钱；广汉北部望风归降。

### 张鲁的军援与绵竹决战前（195年末—196年初）

- 张鲁请求刘官章与刘璋停战，刘官章暂不答应，只给赵韪、[庞义](../historical/pang-yi.md)等人一个限期；[庞义](../historical/pang-yi.md)多次请求归附，赵韪则要求宽限，刘官章一面制造进攻绵竹的压力，一面继续准备巨型投石机。
- 益州内部初步稳定后，刘官章要求张鲁履行西乡铁矿的约定。张鲁以每年约**一万五千斤铁、五千斤铜和三百头耕牛**折纳，暂时维持汉中军备受控。

### 拿下绵竹（196年2月）

- 停战谈判破裂（赵韪拖延），刘官章进兵绵竹（刘焉的最后据点，非成都）。
- 内有[庞义](../historical/pang-yi.md)策应，里应外合。
- 21天攻破；赵韪、刘璋大势已去，宣布投降。
- **益州府库**：扣除赏赐后剩余20亿钱。
- 绵竹没有出现原本预期的天火，刘焉没有提前迁治成都，绵竹因此成为刘璋最后的核心据点。

### 战后安排（196年3月）

| 职位 | 任命 |
|------|------|
| 蜀郡太守 | 甘宁 |
| 广汉郡太守（名义） | 赵韪（降将） |
| 广汉郡实控 | 黄权（督军） |
| 犍为郡太守（遥领） | 洪新甲 |
| 巴东郡 | 严颜 |
| 汉昌令 | 黄权（之前） |
| 锦帆营 | 甘宁（仍任） |

- 东州兵改编：凡百夫长以上军官来安汉军校培训；不接受改编者回家种地。
- 刘官章没有因“拿下益州”而立即继续北伐：先给投降者分地、整编军官、稳定蜀郡和广汉，再考虑汉中。

### 献帝东迁与曹操挟天子（约196年）

- 益州战局收束时，剧情补充了中原政局的新变化：献帝东迁洛阳，曹操即将“挟天子以令诸侯”。曹操把天子迎到许县是第9集才明确交代的后续事件。
- 这一变化解释了后续朝廷封号和刘官章与曹操之间的往来：刘官章仍需面对曹操掌握的名义正统，而益州内部整合尚未完成，暂不急于北出争夺朝廷。

### 新提拔将领（195年）

此战提拔四名底层将领：**周康**（本土寒门）、**胡魁**（少数民族小渠帅）、**石符**（少数民族世家子弟）、**韦世灰**（原师长出身）。

### 投石机与军援（195—196年）

- 攻绵竹时使用可拆装的巨型配重投石机，约能把80斤石弹投到300米；受制于木料、运输和主轴寿命，不能连续长时间射击，但足以压制夯土城墙。
- 张鲁以西乡铁矿履约，每年折纳约1.5万斤铁、5000斤铜和300头耕牛；汉中暂时保留自身政权，刘官章先用这批资源稳定益州军工。

## 历史背景

- **正史**：刘备入益州为建安十六至十九年（211–214年），晚于本剧约18年。
- **赵韪**（正史）：《三国志·蜀书》提到赵韪曾发动叛乱反刘璋，此处改为东州兵将领与刘官章交战。
