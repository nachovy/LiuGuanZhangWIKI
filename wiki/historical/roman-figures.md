# 罗马使团与西方人物

**性质**：历史人物及剧中译名汇总  
**剧情出场**：第37、39集

第37集罗马使团和第39集刘备、关羽出使罗马时，剧情出现多组音译姓名。本页记录能够由语境和历史背景确认的人物：

| 剧情/译名 | 通行写法或身份 | 说明 |
|---|---|---|
| 乌尔比安 | 乌尔比安（Ulpian） | 罗马法学家，剧中作为使团首领或代表出现 |
| 尤利乌斯·保罗 | Julius Paulus | 罗马法学家，与乌尔比安同属法学传统 |
| 赫罗迪安 | Herodian | 罗马史家，剧中参与朝堂和边疆讨论 |
| 狄奥·卡西乌斯 | Cassius Dio | 罗马史家，作为西方人物被提及 |
| 德尔图良 | Tertullian | 基督教作家，作为罗马文化人物被提及 |
| 盖伦 | Galen | 医学家，剧中与汉廷讨论医学和人体知识 |
| 卡拉卡拉 | Caracalla | 约217年前后的罗马皇帝；“盖塔”是其弟而非同一人 |
| 盖塔 | Geta | 卡拉卡拉之弟，剧中罗马政治背景人物 |
| [马克里努斯](macrinus.md) | Macrinus | 卡拉卡拉时期的近卫军团第一勇士，在罗马与关羽比武并败北 |

剧中“大秦”“海西”均指罗马帝国，以上人物均出现在汉罗外交相关叙事中。
